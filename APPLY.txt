TemplytX — Citations + Front-matter + Format-at-export + Template upload
=======================================================================
This ONE bundle contains TWO phases (the citation system you hadn't pushed
yet, PLUS the new front-matter/format/upload work). Copy all files over your
templytx/ folder, preserving paths. No new libraries — but run install anyway:

  npm install
  git add .
  git commit -m "Citations, front-matter, format-at-export, template upload"
  git push origin main

============================ WHAT'S NEW ============================

FROM THE CITATION PHASE (not previously pushed):
- Drag any block to reorder (grip handle on hover); insert blocks BETWEEN
  others (hover the gap) — fixes "can't add a missed section".
- Reference library in the left panel: add by DOI (auto-fetch via Crossref),
  BibTeX paste, or manual form. Click a reference to cite at your cursor.
  The References section GENERATES ITSELF, ordered per template (IEEE numeric
  by appearance; APA/Springer/Elsevier alphabetical). Flows into PDF + Word.
  NOTE: reference library is session-only until the backend (your choice).
  NOTE: Google Scholar links can't auto-fetch (no API) — use DOI or BibTeX.

NEW THIS PHASE:
- FRONT-MATTER: title + authors at the top of the editor. Add authors via
  "+", each with affiliation; click the star to set the corresponding author.
- WRITE ONCE, EXPORT TO ANY FORMAT: content is now decoupled from journal.
  On the Export screen there's a "Target format" picker — export the same
  article as Elsevier, then re-export as Springer with no rewrite. Compliance
  on the export screen checks against whichever target you pick.
- AUTHOR BLOCK TOGGLE on export: "Include authors" (final submission) vs
  "Anonymize" (double-blind review). Authors appear in PDF + Word when included.
- UPLOAD TEMPLATE: dashboard -> "Upload template". Upload a LaTeX .zip or
  .docx; it's stored and named so you can write against it.
  HONEST LIMIT: this stores the template + lets you write against structure.
  Reproducing your institute's EXACT LaTeX-typeset PDF (like Overleaf) needs
  a LaTeX-compilation backend — that's the next big infrastructure phase,
  clearly flagged in the upload screen.

TRY IT
- Open a doc: add a couple of authors up top, star one as corresponding.
- Go to Export: switch "Target format" between Elsevier and Springer and
  watch the compliance score change; toggle Include/Anonymize; Generate.
- Dashboard -> Upload template -> drop any .zip, name it, save; it appears
  in the New Document dropdown.
