TemplytX — Reorder + Citation system
====================================
Copy these files over your templytx/ folder, preserving paths.
No NEW libraries this phase, but to be safe run npm install anyway, then push:

  npm install
  git add .
  git commit -m "Add block reorder + citation system"
  git push origin main

WHAT'S NEW
1. MOVE / INSERT anything:
   - Hover any block -> a grip handle (left) appears -> drag to reorder.
   - Hover BETWEEN blocks -> insert buttons appear -> add a section/text/
     figure/etc exactly there (fixes "can't add a missed section").

2. CITATION SYSTEM (left panel, below Outline -> "References"):
   - Add references three ways: DOI (auto-fetches title/authors/year via
     Crossref), BibTeX paste, or manual form. They join your library pool.
   - While writing: click a reference in the panel to CITE it at your cursor
     in the focused paragraph. A small "Cited as:" preview shows the marker.
   - The References section at the bottom of the document GENERATES ITSELF
     from what you cited, ordered per template:
       * IEEE  -> numbered [1],[2]... in order of appearance
       * APA/Springer/Elsevier -> alphabetical by author
   - Citations + reference list flow into BOTH PDF and Word export.

IMPORTANT LIMITS (honest):
- The reference library is SESSION-ONLY for now — it resets on a hard page
  refresh. It becomes permanent + synced to your account in the backend
  phase. (This was your explicit choice.)
- DOI fetch needs internet and a valid DOI. Google Scholar links do NOT
  work (Scholar has no API / blocks fetching) — use the DOI or BibTeX from
  Scholar's "Cite" button instead.

TRY IT
Open a doc -> in References panel click + -> DOI -> paste 10.3133/pp422H ->
Add. Click into a paragraph, place cursor, click the reference to cite it.
Scroll down: the References section appears automatically. Export to PDF.
