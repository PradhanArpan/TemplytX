TemplytX — Export + structured templates
========================================
Copy these files over your templytx/ folder, preserving paths.
This phase adds new libraries (docx, file-saver), so after copying:

  npm install
  git add .
  git commit -m "Add PDF + Word export and structured templates"
  git push origin main

WHAT'S NEW ON YOUR SITE
- Export finally WORKS. Open any document -> Export -> choose PDF or Word:
    * PDF: opens a print-ready manuscript in a new tab (allow pop-ups),
      formatted to the template (paper size, columns, spacing, font,
      numbered sections) with auto-numbered Figures/Tables/Equations.
      Click "Save as PDF".
    * Word (.docx): downloads a real editable Word file in the same format.
- Templates are now STRUCTURED and cover four document kinds, not just
  journals: Journals (IEEE, Springer, Elsevier), PhD Thesis, Technical
  Report, Grant/Research Proposal. The New Document dropdown groups them.
- Each template has a required-section skeleton. "Check compliance" now
  also flags missing required sections (e.g. Springer needs Declarations).

TRY IT
Create a "Grant / Research Proposal", add a couple of its sections, export
to Word — you get a formatted .docx with numbered sections. Or open the CFD
journal doc and export to PDF to see two-column-capable manuscript output.

NOTE ON POP-UPS: PDF export opens a new browser tab. If nothing happens,
allow pop-ups for your site once.
